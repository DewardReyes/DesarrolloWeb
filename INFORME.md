SmartPhone RD – Informe Fase 1
1. Descripción

SmartPhone RD es un sitio web orientado a la venta y presentación de celulares y productos tecnológicos. En esta primera fase se trabajó principalmente en la estructura visual del sitio utilizando HTML5 y CSS3.

La interfaz fue diseñada con una identidad visual basada en tonos azules, blancos y grises, buscando una apariencia moderna y relacionada con el sector tecnológico.

2. Estructura del sitio

El proyecto cuenta con diferentes secciones y páginas, entre ellas:

Página principal.
Catálogo de productos.
Ofertas.
Productos destacados.
Inicio de sesión.
Panel administrativo.
Carrito de compras.

Para organizar el contenido se utilizaron elementos HTML5 como header, nav, main, section, article, aside, footer, formularios, enlaces y botones.

3. CSS y diseño

El proyecto utiliza hojas de estilos externas para organizar la presentación de sus diferentes áreas:

css/tienda.css: estilos de la tienda principal.
css/login.css: estilos de la página de inicio de sesión.
css/admin.css: estilos del panel administrativo.

Entre los recursos utilizados se encuentran variables CSS, selectores de elementos y clases, pseudoclases, Flexbox, CSS Grid, efectos hover, transiciones y media queries para adaptar la interfaz a diferentes tamaños de pantalla.

4. Control de versiones

Para gestionar el desarrollo se utilizó Git y GitHub.

Durante esta fase se realizaron las siguientes actividades:

Inicialización del repositorio Git.
Creación del primer commit.
Conexión con el repositorio remoto de GitHub.
Creación de la rama fase-1-maquetacion.
Registro de los cambios realizados.
Commit de finalización de la Fase 1.
Creación de una Pull Request hacia main.
Integración de la Pull Request sin conflictos.


5. Conclusión.
La Fase 1 permitió establecer la estructura visual y organización inicial de SmartPhone RD. Se trabajó con HTML5 y CSS3 para crear una interfaz coherente y adaptable, mientras que Git y GitHub facilitaron el control de versiones y el trabajo colaborativo.

El resultado obtenido sirve como base para continuar con las siguientes etapas de desarrollo del sistema.
